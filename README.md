# Smart Floor Manager — 3D Digital Twin
Static single-page app (index.html). Three.js loads from cdnjs.

Run: open index.html, or `npx serve .`
Deploy (Vercel): import folder, Framework "Other", no build command; or `npx vercel --prod`.

Room registry and class schedule are SAMPLE data (see DATA section in index.html). Booking and squad locations are demo only.
